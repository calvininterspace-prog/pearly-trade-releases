# Pearly Trade releases

Signed Windows packages of Pearly Trade. Installed copies check this repository for new
versions and install them automatically; each zip comes with an Ed25519 signature (`.sig`)
that the app verifies before installing anything.

To install for the first time, download the latest `PearlyTrade-Windows-x64-v….zip` from
**Releases**, extract it, and double-click **Start Pearly Trade**.
